# v0.2.3 — filtres catalogue et navigation Stocks

Base indépendante : main `7d7318961588538c7a738ea3e7b8caa105a2501f`.

Le flex aligné en bas incluait le texte d'aide SKU dans la hauteur du composant :
Playwright reproduit un décalage vertical de 24 px à 1440 px. Une grille propre
à `.b2b-catalogue-filters` partage trois lignes (label, contrôle, aide) via subgrid.
Sous 900 px les actions passent sous les deux champs ; sous 600 px tout s'empile.
Les `.b2b-actions` et le catalogue historique ne sont pas modifiés. Les anciens
sélecteurs `.b2b-actions .availability-filter` n'étaient utilisés que par ces
filtres ; ils sont remplacés par les sélecteurs locaux, couverts en navigateur.

L'onglet devient « Stocks » dès que `stock:read` est présent. Le titre et les
explications de la vue distinguent consultation, ajustement (`stock:adjust`)
et import (`import:execute`). Aucun rôle ou droit n'est ajouté ; les boutons
existants et les autorisations BFF/API restent inchangés. Les deux liens utilisés
par la campagne B2B réelle sont repérés par leur route stock ; le nouveau libellé
et les permissions sont vérifiés séparément dans les tests de rôle et UX.

## Validation

- `PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m pytest -q -p no:cacheprovider` :
  3536 réussis, 563 intégrations désélectionnées, 370 sous-tests ; avertissement
  existant sur une clé HMAC synthétique courte.
- `.venv/bin/python scripts/run_evals.py --mode deterministic --suite enriched` :
  122 cas, 0 échec ; pas de qualification de modèle réel.

- `npm test` : 594 tests réussis, dont les quatre rôles et le cas administrateur
  sans `stock:read` (la permission effective fait autorité).
- `npm run typecheck`, `npm run lint`, `npm run build` : réussis, Node 22.19.0.
- `npx playwright test --config=playwright.b2b-ux.config.ts` : 42 réussis.
  Matrice catalogue 1440/1024/768/390 px × FR/EN × clair/sombre ; mesure réelle
  des coordonnées des champs, checkbox et bouton (tolérance 1 px), contrôles
  tactiles ≥ 44 px, ordre Tab, flèches/Entrée/Escape, pagination, filtres combinés,
  SKU exact, absence de débordement, visibilité et requêtes selon les quatre rôles.
- Captures locales inspectées à 390, 768, 1024 et 1440 px, dont le mode sombre.
- Les tests de réponses HTTP périmées restent en place et passent.
- Un premier essai de test EN utilisait un libellé erroné « Check stock » ; corrigé
  vers le libellé existant « Look up stock ». La campagne finale est entièrement verte.

Ces scénarios navigateur interceptent des réponses synthétiques : ils valident
le rendu et les contrats UI, pas un SSO réel. Aucune VM/donnée/dépendance modifiée.
CSS subgrid est vérifié sous Chromium ; Firefox et Safari non exécutés.
