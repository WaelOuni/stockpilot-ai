## Architecture effectivement lancée

Cinq conteneurs sains : web TLS/nginx, API FastAPI/LangGraph, relais d'inférence,
MongoDB **8.3.11** avec authentification et replica set rs0, PostgreSQL
**16.15**/pgvector. Les deux images de données sont épinglées par digest dans
Compose ; les builds utilisent une archive Git du SHA du manifeste, indépendamment
des changements ultérieurs du worktree de scripts ; les images applicatives sont construites avec les Dockerfiles et locks
du commit de référence.
Les réseaux front et data sont internes. Web possède aussi le réseau public local,
le relais le réseau egress. Le backend ne fait confiance qu'au proxy front
`172.30.133.2` pour les en-têtes Uvicorn. Nginx écrase les métadonnées de forwarding,
préserve Host/port et refuse Host/Origin inattendus. Aucun montage n'est partagé
avec une autre installation. Les bind mounts sont ceux de cette candidate et des
scripts versionnés ; Docker Desktop traduit leurs chemins physiques.

Le relais n'autorise que les routes d'inférence et d'inspection du fournisseur,
jamais pull/delete/create de modèles. Seul le fournisseur Ollama Windows est
partagé, via `http://host.docker.internal:11434`. Aucun arrêt, redémarrage ou
changement de sa configuration n'a été effectué.
