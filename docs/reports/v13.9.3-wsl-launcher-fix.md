## Cause établie par reproduction ciblée

Le rapport de campagne précédent et son diagnostic sont conservés hors Git :
`StockPilot-V13.9.3-Cold-Execution-20261023T184920Z-BLOCKED.md` et
`work/storage-refusal-original-cwd.json` dans le répertoire de mission.
Le premier appel de cette campagne n'avait pas conservé son stderr brut ; les
messages et les PID ci-dessous sont ceux des reproductions, pas des PID récupérés
rétroactivement de la tentative initiale.

Ancien appel Windows :
`/mnt/c/Windows/System32/wsl.exe -d docker-desktop --exec sh -c <scan /proc>`.
Il était lancé par Python depuis le checkout Ubuntu
`/home/waelko/projects/stockpilot-v1393-windows-preflight`, après le cd du shell de campagne.
Aucun --cd Linux n'était transmis. L'appel de reproduction pwd retourne
`/root`, code 0, avec :

```text
wsl: Failed to translate '\\wsl.localhost\Ubuntu\home\waelko\projects\stockpilot-v1393-windows-preflight'
```

Pour identifier le parent sans données métier, une reproduction a gardé l'appel
vivant deux secondes avec pwd/sleep. Parent Linux Python : PID 48968,
exécutable `/usr/bin/python3`, PPID 48967.
WMI a observé la chaîne Windows suivante, filtrée par un nonce de diagnostic :

```json
{"pid":4312,"parent_pid":41852,"parent_name":"wsl.exe","nonce_matched":true}
{"pid":41952,"parent_pid":4312,"parent_name":"wsl.exe","nonce_matched":true}
```

Le cwd Windows interne du processus n'a pas été lu dans sa mémoire. Le chemin
UNC est celui que WSL signale comme non traduisible, cohérent avec le cwd Linux
hérité. Les nouveaux tests configurent explicitement le cwd hôte au lancement
et contrôlent le cwd Linux obtenu avec pwd. Ils établissent la cause dans la
reproduction, sans qualifier arbitrairement tous les avertissements WSL de bénins.

## Correction

`scripts/wsl_launcher.py` crée un tableau argv, sans shell, avec :

- cwd hôte `C:\Windows\System32` sous Windows ou `/mnt/c/Windows/System32` depuis Ubuntu ;
- `--distribution Ubuntu --cd /home/waelko --exec ...` pour les commandes Ubuntu ;
- `--distribution docker-desktop --cd / --exec ...` pour les inspections du moteur déjà actif ;
- appels de gestion --list/--version depuis le cwd hôte fixe, sans exécution Linux.

Tout code non nul, stderr non vide (y compris code 0), timeout, exécutable absent,
cwd hôte inaccessible ou arguments invalides reste un refus. Les sorties brutes
des refus restent disponibles en mémoire pour diagnostic, sans les imprimer
automatiquement ni masquer stderr globalement.

Le préflight utilise ce lanceur pour tous ses appels WSL. cscript/WMI reçoit
également un cwd Windows fixe et conserve les contrôles de code, stderr, JSON,
processus, registre et VHDX. Le contrôle WSL/WMI précède désormais toute inspection
Docker dans le runner : un refus ne lance aucune commande Docker en aval.

Le runbook utilise les mêmes wrappers. Les fonctions de copie bornée, les chemins
des quatre volumes, les quotas et la vérification OCI ne sont pas remplacés.
Les contrôles supplémentaires de la campagne sont migrés vers ce même lanceur.
Aucun réglage Windows/WSL/Docker Desktop, politique PowerShell ou protection
système modifié. Aucun Bypass utilisé.

## Périmètre et suite

La revue valide le lanceur, pas les données. Une sauvegarde à froid ne peut
commencer qu'après un préflight frais et positif, avec les six conteneurs arrêtés,
identités attestées, volumes exclusifs, absence d'écrivain connu, WMI/cgroups,
destination privée compatible et réserve physique.

Les commandes Docker de copie du runbook conservent leur traitement historique
de stderr, distinct du lanceur WSL : les codes de retour et la relecture complète
doivent être vérifiés ; ne pas annoncer que des diagnostics stderr de copie ont
été conservés lorsqu'ils ne le sont pas.

Le résultat d'exécution éventuel appartient au manifeste privé et au rapport de
campagne. Même en cas de copie conforme, le statut reste
`cold-physical-unvalidated` et le verdict n'est pas une validation de restauration.
Un refus avant copie exige BLOCKED ; une copie commencée et échouée exige
INCOMPLETE BACKUP — DO NOT RESTORE. Aucun démarrage source ni récupération inclus.
