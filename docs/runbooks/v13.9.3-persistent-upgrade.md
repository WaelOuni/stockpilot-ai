## 8. GO/NO-GO final

GO exige toutes les preuves privées liées dans un manifeste final : code/CI,
inventaire vivant, capacité, absence de pending inconnu, trois backups appariés
complets, relecture/checksums, restore isolé égal, login/tenant/ORDER sur copie,
checkpoint compatible dans les deux sens, export/load des images, transaction
de manifeste répétée, backup final sans nouvelle écriture, fenêtre autorisée.

NO-GO au moindre doute d'intégrité, ressource manquante/étrangère, writer inconnu,
échec d'export, différence métier, restore partiel, manque de place ou autorisation
absente. Arrêter uniquement l'opération concernée ; ne pas corriger les données
ni relancer un service implicitement. Le verdict de cet audit reste BLOCKED.
